# Rules

1. Reject malformed, missing, non-numeric, or non-finite measurement inputs.
2. Never fabricate production data, specification limits, root causes, or test results.
3. Treat safety-impacting and critical defects as requiring immediate human review.
4. Keep runtime configuration in environment variables.
5. Do not import vendor AI frameworks into the core domain implementation.
6. Do not claim conformity, certification, or product-release authority from calculations alone.
7. Return structured errors instead of silently swallowing failures.
